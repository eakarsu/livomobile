LivoMobile Actions

Create an Application

1- Click the plus icon at the left side to open ‘Create New Application’ form

2- Fill the form


Notes:
- Name, Companies, Description and Framework/Template fields are required.
- All authorized companies for a current developer are listed in companies field. To select a company is enough to click on the company at left side.
- If you have a compressed application template with zip format and click the link ‘I want to upload my application template...’, you can upload and then use it to create the application with your custom template.
Figure 3
- If you want, you can select ‘Free Form’ and create your core/simple mobile application.
- If you select ‘JQuery Mobile’ at Framework section, then you can select and use one of the free mobile templates prepared with using JQuery Mobile Framework.
Figure 4


3- After you click ‘Create’ button, the necessary files for demanded infrastructure of the mobile application are installed and shown.

Finally, you have created the Application named 'MyTest'. Now,

1- You can edit and preview your Application

2- You can set the settings of the Application and deploy it.

Edit an Application

After installing your mobile application on Livomobile, you can edit html, javascript and css files.

  1. If you select an html file,
    1. you can review and edit the codes in the editor at the right side


    2. you can display or preview your code by clicking on the ‘Code’ or ‘Preview’ toggle buttons at the right top . You can also review your mobile application by clicking on ‘Preview Application’ icon at the left top of the page




    3. You can add the HTML code structure of the several HTML components to your selected HTML part by clicking on the menu of the several HTML components


    4. you can save or ‘save and deploy’ your code changements by clicking on the ‘Save’ or ‘Save and Deploy’ buttons at the bottom. You can also see the information of the several shortcuts at the bottom and use them. In addition to these, you can deploy your mobile application by clicking on ‘Deploy Application’ icon at the left top of page




    Notes

    As distinct from ‘Save’, if you click on ‘Save and Deploy’ button or ‘Deploy Application’ icon, your code changements will be noticed in 60 seconds and deployed by your mobile container.

  2. If you select a javascript or css file,
    1. you can review and edit the codes in the editor at the right side.
    2. you can save or ‘save and deploy’ your code changements by clicking on the ‘Save’ or ‘Save and Deploy’ buttons at the bottom. You can also see the information of the several shortcuts at the bottom and use them. In addition to these, you can deploy your mobile application by clicking on ‘Deploy Application’ icon at the left top of the page.



  3. If you click ‘Download Application’ icon at the left top of the page and confirm, you can download the zipped file of the selected application.



  4. If you click ‘Delete Application’ icon at the left top of the page and confirm, you can delete the selected application.



  5. If you click ‘Application Properties’ icon at the left top of the page, you can set the several application properties:
    1. Push Notifications
      1. The settings for Android
      2. The settings for iOS




    2. Application Icons and Splash Images
      Developer can upload application icons and splash images with necessary sizes
      1. For Android



      2. For iOS



    3. Deployments
      1. All deployment processes of the current application are listed
      2. If the developer wants to activate a deployment, ‘Activate Deployment’ button can be clicked.

        Alert

        At the same time, only one deployment can be active. So, when a deployment is activated, all others are deactivated.

      3. A deployment can be deleted by using ‘Delete’ button.




    4. Authorization Rules
      1. Authorization Rule for Mobile Authentication like Any, Only Company, Custom Groups, LDAP, Custom Groups with Company or LDAP with Company.
      2. If a developer selects one of the options of Custom Groups or Custom Groups with Company, then the custom groups authorized for the developer is listed.
      3. If a developer selects one of the options of LDAP or LDAP with Company, then the LDAPs authorized for the developer is listed.




    5. Relations
      1. App Owner
        1. When an application is created, its owner is the developer who created it.
        2. The developer and Administrator can change the owner of the application. In the condition, the application can be displayed the new owner(other developers).
      2. 'Companies' List: The authorized companies are displayed and, can be updated.




Administrator

  1. User Management: shows the list of web admin users, i.e, developers Figure 20 The menu appears only for Administrator user.



    1. The Administrator can create new admin user(developer): User Name, Email and Companies fields are required. The Administrator should be careful at the selection of the companies because a developer in LivoMobile could develop only for the selected companies.



    2. The Administrator can update some piece of information of the developer like password, email or companies







    3. The Administrator can delete the web user(developer).



  2. Companies: shows the list of companies used to authenticate at the client side. Besides that, we can create new client, update/delete the company.









  3. Deployments: shows the list of all deployments of the defined application. Besides that, we can activate/delete the deployment.







  4. Client Management: shows the submenus related with iOS/Android Container’s Users (Client).



    1. Custom Groups: shows the list of Custom User Groups, i.e, client groups. Besides that, Administrator can create new group and, update/delete the group









      Notes

      1. Only the companies of the web users are listed in Companies list.
      2. When the web user selects ‘Custom Users’ or ‘Custom Users with Company’ from the settings of an application as an authorized rule, only the saved custom groups of the web users are listed.

    2. Custom Users: shows the list of iOS/Android Container’s users, i.e, clients. Besides that, we can create new client, upload and create the CSV list of clients and, update/delete him/her.















    3. Mobile Devices: shows the list of mobile devices used by clients(the customers of the developers). Besides that, only we can delete a mobile device used by a client.





  5. Service Management: shows the list of service objects used to retrieve / update / delete the data. Besides that, we can add new Service, remove it.



    1. If you click the ‘Add New Service’ button, a select-box to choose a service type and ‘Open Wizard’ button is displayed. You can select the one of 3 service types: REST, SOAP and SAP



    2. If you select the REST service type and click the ‘Open Wizard’ button, then you can see ‘REST Service Wizard’ forms and, fill them



    3. If you select the SOAP service type and click the ‘Open Wizard’ button, then you can see ‘Soap Service Wizard’ form and, fill it



    4. If you select the SAP service type and click the ‘Open Wizard’ button, then you can see ‘SAP Service Wizard’ form and, fill it



    5. If you click ‘Generate’ button, then you can generate and copy the service code to the selected application





  6. Global Settings: contains 3 forms under 3 tabs:

    1. SMTP Server:has fields for configuration parameters of SMTP Server. You can save these and test



    2. Email Templates: stores Email Templates for system emails



    3. Security Settings: sets maximum registered device count for a customer
