Livo is an enterprise mobility platform that allows you to create mobile applications with powerful integration capabilities, without any hassle about technical details.

Responsive Web UI

Create, design and deploy your application. Configure integrations, users and roles. See analytics for your applications. See the preview of your application as you develop it, using LivePreview.

Free-Form Application

Upload the HTML5 application you already have or create one using our intuitive interface. Create files and directories as you need them. Edit HTML, CSS and JavaScript files with syntax highlighting and auto-completion.

Control-Based Application

Create and design your application using the provided UI controls. Use application and screen templates for a starting point. Change theme of your application with a simple user interface. Let our server generate and optimize your application user interface.

Platforms

Our app is available on all popular platforms including Android and Apple. So you can be sure to cover 92.3% of all mobile users [*].

Publish Your App

Applications created with Livo can be packaged with the icon and splash screens of your choice, and published to the application stores of the platforms you want your application support.

Fast. Modular. Scalable. It is Livo Server.

Applications built with Livo can leverage the powerful integration and in-place update capabilities (bypassing the need for repackaging and sending to application stores) of the Livo Server.

Secure

Fine grained security with user-level and company-level authentication and authorization support. Provide different application user interfaces for different entities.

Communication

Binary protocol that optimizes the network bandwidth usage to increase the utilization of cellular networks and wireless. Enterprise-grade communication security with with TLS.

Integration

Unlimited integration capabilities with ServiceObjects and DataObjects APIs. LDAP, SharePoint, SAP... Anything you can think of, thanks to OSGi™-based modular architecture.

In-Place Updates

Deploy your application almost instantly to your customers who already installed your application. Modify your application and just deploy using our intuitive web user interface. No need to repackage the application and go through the application store review phases.

Livo Client Application

Blurring the line between the native and the web.

Custom Branding

Use the application icon and splash screens of your choice.

Push Configuration

Push configurations you made via the Web Administration Panel and let the server push those to your applications. You can even make your application present the configurations you choose to the user.

Incremental Updates

Update your application incrementally when online. No need to download all of the application files, it just downloads the ones you need.

Native Features

Use any of the native features you can think of using our JavaScript APIs. Choose which features to use.

Offline or Online

Use your application even if it is offline. No need to be online if you are not using a remote service.

Data Security

Application data is encrypted using the utilities of the corresponding platform to enhance the security of your data. Only the authenticated user that owns the data can access it.
